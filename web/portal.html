Uso de Media ID en Mensajería

media.send

En cumplimiento del estándar de SocialManager, este proveedor nunca expone URLs directas de Facebook CDN ni rutas del sistema de archivos local.

Al cargar un archivo, se le asigna un identificador opaco mediaId (ej. med_8a3f91...) que se referencia en el endpoint de envío de medios: 

POST /api/v1/sessions/{id}/messages/media
{
  "threadId": "123456789",
  "mediaIds": ["med_..."],
  "text": "Comentario opcional"
}
